🏦 Loan Prediction App

A simple Streamlit application that predicts Loan Approval based on Income and Credit Score using a Logistic Regression model.

📌 Features

🔢 User inputs Income

📉 User inputs Credit Score

🤖 ML model predicts Loan Approval (Approved / Rejected)

🎨 Clean and interactive Streamlit UI

💡 Beginner-friendly project

📂 Project Structure
loan-prediction/
│── loan_prediction_app.py
│── README.md
│── requirements.txt

🧠 Model Details

This project uses a simple Logistic Regression model trained on sample data:

Input features:

Income

Credit Score

Output:

1 → Loan Approved

0 → Loan Rejected
